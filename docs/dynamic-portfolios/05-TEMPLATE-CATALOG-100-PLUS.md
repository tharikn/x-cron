## Variation requirements

Every template should vary at least three dimensions:
- information architecture
- composition
- typography
- navigation
- section order
- imagery
- card system
- color system
- motion language

## Required metadata

Audience, visual family, content density, mobile behavior, dark/light support, accessibility rating, performance budget, supported sections, preview and version.

## Quality gate

Every template must pass:
- 320px to large desktop
- keyboard navigation
- 200% zoom
- reduced-motion
- no horizontal overflow
- accessibility checks
- long-text stress test
- missing optional section test
- light/dark test
- performance budget

## Trend policy

Support 2026 patterns such as editorial/index layouts, bento/card composition, expressive typography, restrained glass effects, purposeful motion, dark mode, collage/texture, neo-brutalism and immersive presentation. These are design options, not mandatory effects.
