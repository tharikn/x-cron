# SEO, AEO and Machine Readability

## Per-page metadata

Title, description, canonical, robots, Open Graph, social preview, locale and alternate hreflang.

## Structured data

Generate JSON-LD from trusted structured fields for Person, ProfilePage, WebSite, CreativeWork, Article and BreadcrumbList when applicable.

Do not allow arbitrary JSON-LD script injection in v1.

## Semantic HTML

Map components to semantic elements such as header, nav, main, section, article, footer, headings and lists.

## Machine-readable profile

Keep important facts structured:
- name
- role
- location
- skills
- experience
- projects
- education
- contact
- social profiles

## Sitemap

Generate from published pages only.

## Robots

Public published sites are indexable by default. Draft and preview must be noindex.

## Canonical

Canonical URLs must not contain preview/query parameters.

## Principle

Machine readability should come from structured content and semantic HTML, not hidden keyword stuffing.
