# Admin Template Governance

## Admin functions
Create/import template, preview assets, validate manifest, run accessibility/performance checks, approve/reject, version, deprecate, archive, inspect usage and review reports.

## QA pipeline
1. Schema validation
2. Component compatibility
3. Responsive test
4. Accessibility test
5. Visual regression
6. Performance budget
7. Content stress test
8. Security review
9. Human design review
10. Approval

## Immutability
Never mutate a template version used by published sites. Create a new version.

## Fixtures
Test short content, long content, missing optional fields, multiple locales, large images, no images, light/dark and reduced motion.

## Governance metadata
Reviewer, approval time, compatibility, changelog and known limitations.
